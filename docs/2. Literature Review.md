## 🔹 Big Data Analytics

Big Data refers to the processing and analysis of large, complex datasets that cannot be handled using traditional systems.

It is characterized by:

* Volume
* Velocity
* Variety

Modern tools such as distributed systems and columnar databases enable efficient handling of such data.

---

## 🔄 ETL vs ELT

### ETL (Extract, Transform, Load)

* Data is transformed before loading
* Suitable for traditional systems

### ELT (Extract, Load, Transform)

* Data is loaded first, then transformed
* Better suited for modern data warehouses

This project adopts **ELT architecture** for scalability and flexibility.

---

## 🏗️ Data Warehousing

A Data Warehouse is a centralized repository used for reporting and analysis.

Key characteristics:

* Subject-oriented
* Integrated
* Time-variant
* Non-volatile

The project uses **ClickHouse** as an OLAP database for high-performance analytics.

---

## 🧱 Medallion Architecture

A layered data architecture used in modern analytics systems:

### Bronze Layer

* Raw data ingestion
* Minimal processing

### Silver Layer

* Cleaned and structured data

### Gold Layer

* Aggregated data for business insights

This architecture improves data quality and maintainability.
