# 📋 Requirements Gathering

## Yaseer Operations Big Data Analytics Platform

---

## 🔹 Functional Requirements

* Capture data changes from LIS database
* Stream data using message broker (RabbitMQ)
* Store raw data in Data Warehouse
* Transform data into structured models
* Provide dashboards and reports
* Support multiple user roles

---

## 🔹 User Roles

* **Data Engineer:** Manage pipelines and infrastructure
* **Data Analyst:** Analyze data and create dashboards
* **System Admin:** Monitor system performance
* **Business User:** View reports and insights

---

## 🔹 Use Cases

* Monitor laboratory performance
* Analyze number of tests performed
* Detect delays in operations
* Generate management reports
* Track system activity logs

---

## 🔹 Non-Functional Requirements

### Performance

* Fast query execution using ClickHouse

### Scalability

* Handle increasing data volume

### Reliability

* Fault-tolerant pipelines

### Security

* Role-based access control

### Maintainability

* Modular and clean architecture
